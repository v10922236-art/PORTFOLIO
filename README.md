# Vaishnavi R — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Included
- Responsive layout for desktop/tablet/mobile
- Dark/light mode with localStorage
- Scroll reveal animations
- Reading progress bar
- About, Education, Skills, Projects, Certifications and Contact sections
- GitHub and LinkedIn links
- Resume download button

## Run locally
Open `index.html` in a browser.

## Resume
Place your resume PDF in this folder with the filename:
`Vaishnavi_R_Resume.pdf`

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `Vaishnavi_R_Resume.pdf`.
3. Open repository Settings → Pages.
4. Choose "Deploy from a branch".
5. Select the `main` branch and `/root`.
6. Save and open the generated GitHub Pages URL.
